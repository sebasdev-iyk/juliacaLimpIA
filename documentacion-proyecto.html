Rutas de Limpieza Inteligentes

Documentación Técnica — Hackathon 2026
Puno, Perú

Sistema de optimización de rutas de recolección de basura usando visión por computadora (YOLO-World) y algoritmos de ruteo inteligente. Convierte fotos ciudadanas en rutas de limpieza prioritarias.

1. Visión General del Sistema

El sistema resuelve el problema de las rutas fijas de recolección de basura que no responden a la demanda real, generando acumulación de residuos en zonas críticas, pérdida de tiempo y combustible.

Flujo principal:

📸 Foto → 🧠 Análisis IA → 🗺️ Mapa → 🚛 Ruta Inteligente
  1. Reporte: Ciudadano sube foto y marca ubicación en el mapa
  2. Análisis IA: YOLO-World detecta objetos (contenedores, bolsas, desbordes) y calcula severidad
  3. Visualización: Los reportes aparecen en el mapa con colores según nivel (Crítico/Medio/Bajo)
  4. Ruta Inteligente: Algoritmo genera la ruta óptima priorizando puntos críticos por cercanía

3. Detección de Basura con YOLO-World

3.1 ¿Qué es YOLO-World?

YOLO-World es un modelo de detección de objetos zero-shot de última generación. A diferencia de los modelos tradicionales que solo detectan clases pre-entrenadas fijas (como COCO con 80 clases), YOLO-World permite definir cualquier lista de clases en tiempo de inferencia sin necesidad de re-entrenar. Esto lo hace ideal para detectar basura, ya que el vocabulario es muy variado.

3.2 Vocabulario de Detección

El sistema define 112 clases en español e inglés organizadas en categorías:

CategoríaEjemplos
Contenedoreswaste container, dumpster, trash can, contenedor de basura
Desbordesoverflowing dumpster, full garbage container, overfilled dumpster
Bolsastrash bags, garbage bags, bolsas de basura
Acumulacionesgarbage pile, pile of trash, construction debris
Basura individualbottle, can, paper, plastic bag, tire, electronic waste
Items callejeros (Perú)mascarilla, vaso plastico, cascara, zapato, colchon

3.3 Fallback Chain

El detector implementa una cadena de resiliencia:

  1. YOLO-World (yolov8s-world.pt) — intenta cargar el modelo completo
  2. GPU/CUDA — si hay GPU disponible, el modelo se mueve a CUDA para aceleración
  3. Frontend fallback — si el backend no está disponible, el frontend usa un analizador simulado

4. Cálculo de Severidad

El archivo severity.py implementa la lógica que convierte las detecciones del modelo en niveles de severidad accionables.

El sistema aplica 9 reglas jerárquicas en orden de prioridad:

5Bolsas + basura individual combinadosMedio

7Contenedor solo y limpioBajo
81-2 objetos individuales solosBajo
9Sin detecciones relevantesBajo

5. Algoritmo de Ruta Inteligente

El algoritmo está implementado en src/utils/routeOptimizer.js y combina ordenamiento por prioridad con la heurística del vecino más cercano.

5.1 Lógica del Algoritmo

1. Asignar peso numérico a cada nivel:
     Crítico = 3, Medio = 2, Bajo = 1

2. Ordenar todos los reportes por prioridad descendente

3. Para cada grupo del mismo nivel de prioridad:
   a. Empezar desde el punto actual (municipalidad primero)
   b. Elegir el punto MÁS CERCANO al actual (distancia Haversine)
   c. Avanzar a ese punto y repetir

4. Calcular métricas finales:
   - Distancia total (Haversine entre puntos consecutivos)
   - Tiempo estimado (velocidad promedio 30 km/h)
   - Combustible (0.4 L/km)
   - CO₂ evitado (2.68 kg/L de combustible)
   - Ahorro % vs ruta fija (22% más larga)

5.2 Distancia Haversine

Para calcular distancias entre coordenadas GPS se usa la fórmula de Haversine, que calcula la distancia del gran círculo entre dos puntos en una esfera (Tierra, R=6371 km):

d = 2R · arcsin(√(sin²(Δlat/2) + cos(lat₁)·cos(lat₂)·sin²(Δlng/2)))

5.3 Ruteo por Calles Reales (OSRM)

Además de la ruta en línea recta, el sistema se conecta a la API pública de OSRM (Open Source Routing Machine, basada en OpenStreetMap) para obtener rutas que siguen calles reales:

  • URL: https://router.project-osrm.org/route/v1/driving/{coordenadas}?geometries=geojson
  • Parámetros: coordenadas en formato lng,lat separadas por punto y coma
  • Respuesta: GeoJSON con la geometría de la ruta, distancia y duración

Si OSRM no está disponible (sin internet), el sistema simula la ruta generando puntos intermedios con desviaciones senoidales y aumentando la distancia un 25% sobre la línea recta.

Nota: OSRM es una API pública gratuita sin necesidad de API key, pero tiene límites de uso. Para producción, se recomienda hostear un servidor OSRM propio.

9. Cómo Ejecutar

Prerrequisitos: Node.js 18+, Python 3.10+, pip

Backend (IA)

cd rutas-limpieza-inteligentes/ai-service
pip install -r requirements.txt
python3 main.py
# → Servidor en http://localhost:8000

Frontend

cd rutas-limpieza-inteligentes
npm install
npm run dev -- --host
# → Servidor en http://localhost:5173
Nota: El modelo YOLO-World (~80 MB) se descarga automáticamente la primera vez desde la caché de Ultralytics. Si no hay GPU, se ejecuta en CPU. Sin backend, el frontend usa un analizador simulado.
